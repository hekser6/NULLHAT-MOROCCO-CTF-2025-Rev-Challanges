# elite_banker

## Description

After a wild night of partying, you wake up with an empty wallet and a growling stomach. You spent every last penny on drinks and good times, but now reality hits hard - you need money for food.

Walking down the street, you spot an ATM machine from ELITE BANK. Maybe, just maybe, if you can hack into this ATM system, you'll be able to feed yourself...

Can you bypass the security and recover the access code?
