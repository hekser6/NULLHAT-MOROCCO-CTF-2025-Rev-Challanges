# lmakla_drestau - Reverse Engineering Challenge

**Difficulty:** Easy 
**Category:** Reverse Engineering

## Description
It's dinner time at the school, and you're starving! The school restaurant is running a special contest - if you can crack their secret system, you'll win an extra meal for dinner tonight!

The restaurant staff has created a mysterious program that guards the secret phrase. Only those who can reverse engineer it and discover what she said will earn their bonus meal.

Can you crack the code before dinner ends? Your extra meal awaits!
